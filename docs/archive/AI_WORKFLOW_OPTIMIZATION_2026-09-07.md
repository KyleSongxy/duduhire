# 双端 AI 梳理与匹配优化验收

更新：2026-09-07。交付位置为本地 AI Marketplace，入口 `/talent` 与 `/projects`。沿用原品牌、配色、导航、输入区、对话区和能力卡视觉设计。

## 用户现在如何完成

1. 直接粘贴需求、简历段落或项目经历，不必先拆成表格。示例按钮只填入可修改文字，不自动发送；未替换的示例标记不会被当成真实经历。
2. 一轮同时整理已知信息，只问必要缺口。需求的背景、工作、结果齐全，或能力的背景、本人职责、行动、结果齐全，即可查看草稿；预算、证明材料与偏好可以之后补充。
3. 在草稿中核对字段和原文依据；点击修改可回填到输入框，也可直接说“把预算改成……”。未发送文字不会被快捷操作覆盖，有未提交修改或附件时不能误确认旧版本。
4. 确认后自动带入匹配摘要、技能和明确的合作条件。技能可取消、补充与搜索；折叠的条件摘要也显示已知市场、语言、预算、时数与日期，避免隐藏限制。
5. 可以直接私密查看示例匹配。参与真实用户匹配仍需检查公开预览、勾选同意并主动发布；查看示例不会公开资料。

修改后需要重新确认。已有版本、并发校验、重复请求恢复、撤回与未发送输入恢复继续保留。历史回复可展开，当前草稿只完整展示一次，减少重复阅读。

## 解析与可信边界

- 模型负责理解、字段归类、选取证据、提问与建议方向。`provided` 字段的最终值来自能逐字定位的用户原句或材料；不会保留模型补写的工具、职级、个人贡献或指标。
- 模型把“二十四小时”改写成“24小时”等未使用输出，不再使有真实原文的整轮解析失败。它补写的“独立完成”“已上线”等也不会进入事实字段。
- 引用必须能定位到具体来源。只有拆开的每一段都逐字存在同一来源，才修复模型拼接的不连续引用；虚构或错误来源仍拒绝。
- 截断引用含否定、限定或他人归属时，补回同分句的必要原文；例如“模型微调”不能脱离“我没有做过”，普通短引用保持简短。这项规则也用于旧档案的匹配建议。
- 旧版已确认档案也按真实消息和材料中的引用生成新匹配建议，排除旧 `value` 的 AI 扩写。不会改写历史存储。
- 保留“没有统计数据”“由同事负责”“德语是加分项”“预算未定”等限定，区分本人工作、团队成果、愿望和已实现结果。
- 已确认后说“没有材料”，会撤回旧的材料声明并重新待确认；其他已说清的事实保留。
- 提示版本 `duduhire.discovery.v2.1`，JSON `schemaVersion` 仍为 `2`。Qwen 不可用时显示错误并保留输入，不冒充已经完成 AI 分析。

## 知识与匹配

知识库包含 7 类工作场景和 34 项受控技能，重点覆盖知识库/RAG、业务自动化/Agent、模型评测、海外市场调研、获客、内容本地化、渠道协作。每类记录工作缺口、问题、证据检查方向和官方来源；方法参考不充当用户能力证据。

研究采用 Upwork 的需求理解与资料结构、Toptal 的工作样本方法，以及 NIST 和 Trade.gov 的领域框架。来源、采用方式及维护说明见 [知识库研究](../AI_MATCHING_KNOWLEDGE_2026-09-07.md)。额外参考了 [Upwork 对 Uma 招聘流程的官方介绍](https://www.upwork.com/blog/uma-recruiter-how-we-built-an-agentic-solution-to-talent-matching-and-hiring)，落实为从描述提取条件、保留核对环节、说明推荐依据。

匹配只比较数据库中的相应记录，不由模型编造候选人或匹配百分比。结果展示共同能力、条件相容处、缺口和下一步核实问题。必须技能与明确不兼容条件会排除；未填信息不会当作符合。市场和语言依照工作陈述，预算只有金额、币种、计价周期明确时才比较；不自动换汇。时间区分需求方最低投入/最晚开始与人才可投入上限/最早开始。

已修复“先不投 Google Ads”误作广告能力、“同事负责”误作本人技能、仅提到 Shopify 就认定跨境运营等问题。AI 与出海的自然说法通过领域上下文和工作动作映射到受控技能，保留原句供核对。

## 本地数据库

已应用 `008_matching_knowledge_and_examples.sql`。`matching_examples` 独立保存 **22 条示例**，包括 11 条需求、11 条人才；AI 方向 5 对，企业出海方向 6 对，版本 `2026-09-07.2`。包括德国 B2B 兼职拓展、美国英文内容本地化和 n8n 兼职等具体场景。

示例没有用户账户、联系人或真实发布身份，只能通过明确标识的示例预览展示；不会进入真人候选集合。已重复执行导入并查询数量，仍为 22 条。运行时只能读取示例，不能写入或删除。

正常配置本地数据库后可重复执行：

```sh
npm run db:migrate
npm run db:seed:matching
```

当前电脑使用既有私有开发环境文件注入数据库配置；本报告不包含凭据。

## 仍然适用的产品边界

本次为本地实现与验证，没有部署生产。真实匹配依赖用户主动发布的实际供给；示例数量不代表真实人才数量。用户确认表述不等于平台认证，预算可相容不等于已达成合作。站内联系、消息、签约和付款未在本次实现。附件仍支持文本摘录，未声称已经实现 PDF/Word 全文解析或原文件托管。
