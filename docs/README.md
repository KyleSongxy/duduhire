## 维护约定

接口与配置以源码为准，功能边界汇总在 PRODUCT。完整规则只维护在对应主题文档，README 保持入口作用。需求先标记待实施，代码与必要验证完成后再更新“已实现”。不批量改写历史验收结果，不删除数据库历史迁移。

每次修改运行 `npm run check`，其中 `check:repository` 检查核心文档相对文件链接以及 Web 源码、入口 HTML 的静态图片和字体引用。它不验证远程网址、Markdown 锚点、动态构造路径或真实页面效果；涉及页面布局和交互时仍需浏览器检查。

媒体逐帧缓存和 Python 字节码不纳入版本控制；现役影片、可编辑工程、素材输入和 QA 结论保留。`service-worker.js` 是旧站缓存退役入口，即使当前页面不注册也不能按“没有引用”删除。历史工具是否仍有生成依赖必须先查证。
